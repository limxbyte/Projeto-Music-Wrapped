# 🎧 Music Wrapped 2026

Projeto pessoal desenvolvido durante meus estudos de programação, inspirado nas retrospectivas musicais.

## ✨ Sobre o projeto

O Music Wrapped apresenta uma retrospectiva musical interativa, com destaques de artistas, músicas favoritas, gêneros musicais e outras estatísticas em uma interface dinâmica.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

## 📚 Objetivo

Praticar desenvolvimento web, organização de código, manipulação de elementos com JavaScript e versionamento de projetos utilizando Git e GitHub.
